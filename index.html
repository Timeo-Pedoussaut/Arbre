Publier mes modifications

Les changements faits ici ne sont visibles que dans ce navigateur. Pour les mettre en ligne :

  1. Télécharge le fichier à jour (data.js, ou un .zip s'il y a de nouvelles photos).
  2. Sur GitHub, ouvre ton dépôt, puis Add file → Upload files et dépose data.js (et le dossier photos si tu as choisi le zip, après l'avoir dézippé).
  3. Clique sur Commit changes. Le site se met à jour en une minute environ.
